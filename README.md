# Python Projects & Skills Showcase

A curated collection of Python scripts, applications, and algorithmic challenges built while completing certifications (such as freeCodeCamp's Scientific Computing with Python) and independent practice projects.

---

## 📌 Featured Projects & Modules

| Directory | Source / Platform | Focus Areas | Description |
| :--- | :--- | :--- | :--- |
| `freecodecamp/` | freeCodeCamp | Fundamentals, Data Structures | Solutions and projects built for the *Scientific Computing with Python* certification. |
| `algorithms/` | Custom Practice | Searching, Sorting, Logic | Implementations of standard algorithms and problem-solving exercises. |
| `mini_apps/` | Personal Projects | OOP, CLI, File I/O | Small utility tools and interactive command-line projects. |

---

## 🛠️ Key Topics Covered

- **Core Python:** Functions, Flow Control, Scope, Collections (Lists, Dicts, Sets, Tuples)
- **Object-Oriented Programming (OOP):** Classes, Inheritance, Encapsulation
- **Algorithmic Thinking:** Recursion, Time Complexity, Data Manipulation
- **File I/O & Automation:** Processing raw text files, JSON handling
